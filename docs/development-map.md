# Карта зависимостей развития Avi-Bro (текстовый формат)

Только текст и стрелки; можно отдать нейросети для отрисовки или начертить от руки.
Составлена по коду (config.js, js/skills.js, js/sim.js, js/main.js); цифры - хардкор из config.js, аркада переопределяет их в arcade.js.

```
ЦИКЛ СУТОК (победа - пережить 99 ночей)
  День -> Ночь -> Рассвет -> День ...
  Рассвет -> героям +1 уровень
  Рассвет -> монстрам +1 уровень (окрепли)
  Рассвет -> списание содержания построек

ПРОКАЧКА 1: УРОВНИ (за пережитые рассветы)
  Рассвет -> +1 уровень -> выбор умения (1 из 3) -> умения-характеристики
  Каждый 10-й уровень -> супер-умение (14 шт, каждое один раз)
  Босс -> +1 доп. выбор умения каждому герою
  Казна -> смена вариантов выбора: 30 -> 50 -> 70 монет
  Уровень костра -> редкость вариантов: Обычное -> Улучшенное -> Редкое -> Легендарное
  Профессия -> личные умения в пуле выбора
  Кооп: есть профессия-партнёр -> выпадают синергии (12 шт)
  Торговец (раз в 3 дня) -> умения за монеты (6/12/20/32) -> в коллекцию
  Умение до Легендарного у торговца -> ещё 1 железо
  Всего умений: 67 обычных + 14 супер

ПРОКАЧКА 2: ОПЫТ (за убийства)
  Монстры + сундуки + покупка опыта -> шарики опыта -> уровень опыта
  Уровень опыта -> выбор нового или улучшение боевого навыка
  Ограничение: максимум 3 навыка, каждый до 7 уровня
  Уровни 4-7 навыка -> требуют железо: 1 -> 2 -> 3 -> 4
  Все 3 навыка на максимуме -> опыт даёт МАСТЕРСТВО (7 бонусов, берутся без предела)
  Кооп: напарник получает 50% опыта

КОСТЁР (ось развития)
  Брёвна (x1) + уголь (x30) -> топливо -> шкала заполнена -> уровень костра +1 (макс. 5)
  Уровень костра -> редкость умений (см. выше)
               -> территория: 320 -> 450 -> 600 -> 780 -> 900
               -> туман войны: 1250 -> 1800 -> 2450 -> 3300 -> весь мир (5 ур.)
               -> свет + лечение + урон по монстрам
               -> локации растут: стражи сильнее, сундуки богаче
  Костёр погас -> кухня не готовит

РЕСУРСЫ И ПРОИЗВОДСТВО
  Дерево -> топор -> брёвна -> лесопилка -> доски -> постройки и улучшения
  Брёвна -> костёр (топливо)
  Лесопилка (мод Углежог) -> уголь -> костёр
  Ягоды/грядки/мясо -> кухня -> готовая еда -> сытость и лечение; излишки -> лавка
  Шкуры -> лавка -> монеты
  Мастерская 3 ур. + 30 монет + 30 досок + 1 железо -> кирка (или торговец за 55 монет)
  Кирка -> камень и железо
  Железо -> уровни навыков 4-7 + улучшения зданий высоких уровней + Легендарные умения
  Камень -> улучшения зданий высоких уровней
  Топор: 4 улучшения -> монеты + доски, на 3-4 ур. ещё железо (в мастерской)

КАЗНА (монеты общие)
  Приход: монстры и боссы -> монеты
          лавка -> выручка;  биржа -> майнинг + курс AviCoin
          ратуша -> налог за постройки;  сундуки -> монеты
  Расход: содержание построек каждый рассвет
          (нет денег -> турели выключены, кухня и лесопилка вполовину)
          торговец -> умения;  смена вариантов выбора;  топор;  модификации зданий (15 досок + 10 монет)
  Казна -> покупка у поселений: еда, уголь, железо, камень, доски, опыт, рюкзак+, кирка

МИР
  Монстры -> опыт, монеты, мясо, шкуры
  Боссы: с 5-й ночи, каждые 5-7 ночей (giant -> packlord -> witch -> golem)
       -> монеты, брёвна, уголь, железо, шкуры + доп. выбор умения каждому
  26 логов -> стражи (сила = глубина + ночь + уровень костра) -> сундуки
  Сундуки -> опыт, монеты, уголь, рюкзак+; железо - в дальних и скрытых
  Глубина леса -> монстры сильнее, но опыт +150% и монеты +200%
  Поселения 4 сторон света (безопасны) -> торговцы
  Одежда у торговцев -> характеристики; сила растёт с днями (+3%/день)

ПРОФЕССИИ (выбор на старте)
  Охотник -> лук, метки на врагах, лавка, скидка 25% у торговца
  Инженер -> ключ, турели, пушка на вышку, мастерская
  Программист -> лазер, дрон, модули на постройки, биржа
  Архитектор -> молоток, частокол, вышка, ратуша, постройки на 40% дешевле
  Пушка инженера -> ставится на вышку архитектора
  Модули программиста -> усиление турелей, вышек, стен, костра

ГЛАВНЫЙ ЦИКЛ
  Характеристики героя -> боевая мощь -> быстрее монстры
    -> больше опыта и монет -> сильнее герой и лагерь -> ...
```

## Ключевые пороги (хардкор, config.js)

- Опыт на уровень n: 7 + 7(n-1) + 1.5(n-1)^2, потолок 600 (XP_NEED).
- Ступени топлива костра: 20/90/135/180/225 (FIRE_LEVEL_STEPS).
- Железо на уровни боевого навыка 4-7: 1/2/3/4 (ABILITY_IRON).
- Кирка: мастерская 3 ур., 30 монет + 30 досок + 1 железо (PICKAXE_CRAFT).
- Боссы: 1-й на 5-ю ночь, дальше каждые 5-7 (BOSS_FIRST_NIGHT, BOSS_EVERY_MIN/MAX).
- Модификация здания: 15 досок + 10 монет (MOD_COST).
