# Balance + XP до 99 ночи + склад шкур Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Починить баланс (скейл монстров, XP-кривая, экономика), растянуть прокачку боевых навыков до 99-й ночи и убрать проблему шкур через новое строение-склад с ПКМ-сдачей. Обучение (туториал) — вне скоупа по решению заказчика.

**Architecture:** Task 1 — только значения `config.js` (безопасно, откат одной строкой). Task 2 — формулы опыта + 6–7 уровни навыков (`config.js` + `js/sim.js`). Task 3 — новое лагерное строение по образцу лесопилки/лавки (`config.js` + `js/sim.js` + `js/main.js` + `js/render.js` + net-синхронизация). Task 4 — точечные формулы боя/наград в `js/sim.js`. Task 5 — конфиг-QoL без UI-перестроек.

**Tech Stack:** Ванильный JS (глобалы `window.CONFIG`, `window.AB`, IIFE-модули), canvas-рендер, `server.py` (stdlib, не трогаем). Тестового фреймворка в репо нет — проверка: `node --check`, `python3 -c ast.parse`, ручной чек-лист в браузере (см. AGENTS.md). Новый tooling не добавляем.

**Spec:** Аудит баланса/геймплея из чата 2026-09-28 (spike-репорт: 15 пунктов баланса + 7 категорий идей) + уточнения заказчика: (а) обучение не делаем; (б) излишки опыта → продлить прокачку скилов до 99 ночи (не конвертация); (в) шкуры → новое строение, сдача правой кнопкой. Источники истины: `config.js` (819 строк), `js/sim.js`, `js/main.js`, `README.md`.

## Global Constraints

- Не добавлять сборку, npm, тесты-фреймворки, CI — репо статическое (AGENTS.md).
- Все новые строки UI и комментарии — по-русски.
- Порядок скриптов в `index.html` не менять; новые модули не создавать — править существующие.
- Неймспейс `window.AB`, конфиг `window.CONFIG`; сетевой протокол `Net` — обратно совместим (гость/хост на старой версии не требуем, но сейв/лоад `so`/`stc` не ломаем молча — расширяем массивы только в конец).
- `.nojekyll` не трогать; деплой — пуш в `main`.

## Review Focus

- Гость/хост с новым полем `G.store.hides`: гость не шлёт `so`, только хост — проверить, что гость видит счётчик после снапшота.
- Старые сейвы без `so[11]` (hides): загрузка не должна дать `NaN` — дефолт `|| 0`.
- Двойное списание шкур: лавка тянет из `store.hides`, игрок одновременно сдаёт — порядок операций за тик детерминирован.
- Железо на 6–7 ур. навыков при пустом складе: оффер с `iron > 0` не блокирует выбор (действует правило «хотя бы один бесплатный вариант», `sim.js:890`).
- XP-скейл от ночи не должен ускорить раннюю игру: множитель `1 + 0.02*night` на ночи 1 ≈ 1.02 — пренебрежимо.
