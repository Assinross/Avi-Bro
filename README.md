# Avi-Bro: 99 ночей в лесу

Браузерная 2D-игра на выживание для одного или двух игроков. Работает в любом современном браузере на ПК без установки.

## Как опубликовать на GitHub Pages (один раз)

1. Загрузите содержимое этой папки в репозиторий `https://github.com/Assinross/Avi-Bro` (в корень, рядом с `index.html`):
   ```bash
   cd ~/avi-game/avi-bro
   git init
   git remote add origin https://github.com/Assinross/Avi-Bro.git
   git add .
   git commit -m "Avi-Bro: первая версия игры"
   git branch -M main
   git push -u origin main
   ```
2. На GitHub откройте **Settings → Pages**. В разделе **Build and deployment** выберите *Source: Deploy from a branch*, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
3. Через 1–2 минуты игра будет доступна по адресу:
   **https://assinross.github.io/Avi-Bro/**

## Как обновить игру

После любых изменений в папке:
```bash
cd ~/avi-game/avi-bro
git add .
git commit -m "что изменилось, например: усилил монстров"
git push
```
Сайт обновится через 1–2 минуты. Если браузер показывает старую версию, обновите страницу через `Ctrl+Shift+R`.

## Игра вдвоём

### Способ 1 — свой сервер в один клик (рекомендуется, интернет для игры не нужен)

**Первый раз** (на компьютере, где будет сервер, обычно на Ubuntu):
1. Откройте https://assinross.github.io/Avi-Bro/ → **Игра вдвоём** → **Скачать для Linux** (или для Windows).
2. Запустите скачанный файл: Linux — `bash ~/Загрузки/start-server.sh`, Windows — двойной клик по `start-server.bat`.

Скрипт сам:
- скачивает **последнюю версию игры** с GitHub в папку `~/avi-bro-server` (Windows: `%USERPROFILE%\avi-bro-server`);
- добавляет в меню приложений (Windows: меню «Пуск») значок **«Avi-Bro сервер»** — дальше запуск только им, в один клик, и каждый запуск сначала обновляет игру;
- запускает сервер и открывает игру в браузере.

**Ссылка всегда одна и та же:** `http://<имя-компьютера>.local:8067` (например, `http://assinross-pc.local:8067`). Сервер пишет её при запуске и показывает в меню игры (**Игра вдвоём**). Откройте её на втором компьютере один раз и сохраните в закладки. Если имя `.local` не открывается, рядом показана запасная ссылка по IP.

**Как играть:** на одном компьютере **Игра вдвоём → Создать комнату**, на втором в том же меню появится **«Комнаты в сети»** — нажмите **Войти**. Коды и приглашения не нужны.

**Обновить игру,** не перезапуская сервер: **Проверить обновление** в главном меню (или **Игра вдвоём → Обновить игру до последней версии**). На GitHub Pages эта же кнопка сверяет файлы игры с сайтом и перезагружает страницу, если вышла новая версия. Если сервер запущен из папки разработки с `.git`, обновление откажется, чтобы не затереть ваши правки - там используйте `git pull`. Сервер скачивает то, что запушено в ветку `main`, заменяет только изменившиеся файлы, удаляет файлы, которых в игре больше нет, и перезапускается. Если ничего не поменялось — пишет «Уже последняя версия» и не перезапускается.

**Остановить сервер:** кнопка **Игра вдвоём → Остановить сервер** (нажать два раза), или закройте окно терминала, или Ctrl+C в нём.

**Два сервера сразу не запустятся:** если сервер уже работает, значок «Avi-Bro сервер» просто откроет игру в браузере. Если порт 8067 занят чужой программой, сервер так и напишет — запустите на другом порту: `python3 server.py 8090`.

**Защита от мусора:** брошенные комнаты удаляются сами (не больше 30 комнат), слишком большие сообщения и зависшие подключения обрываются, от обновлений не остаётся временных файлов, правило брандмауэра Windows добавляется один раз.

**Тормозит в браузере?** Игра оптимизирована и для браузеров без видеокарты (так рисует Яндекс Браузер в режиме энергосбережения): спрайты кэшируются уже в нужном масштабе, туман и свет считаются на маленьком слое, спрятанное в тумане не рисуется. Если всё равно рывки — в Яндекс Браузере выключите «Режим энергосбережения» и включите «Использовать аппаратное ускорение, если возможно», потом перезапустите браузер. Игра сама включает облегчённую графику, если кадры стабильно медленные; переключатель есть в меню паузы.

Если второй компьютер не открывает страницу:
- разрешите порт в брандмауэре на ПК с сервером: `sudo ufw allow 8067` (Linux) или нажмите «Разрешить доступ», когда Windows спросит про Python;
- проверьте, что оба устройства в одной сети, а не в «гостевой» сети роутера (она изолирует устройства друг от друга).

Вручную без скрипта: `python3 server.py` в папке с игрой (другой порт: `python3 server.py 9000`). Нужен только Python 3.

### Способ 2 — через интернет (GitHub Pages + PeerJS)

Откройте https://assinross.github.io/Avi-Bro/ на обоих ПК. Компьютеры находят друг друга через бесплатный облачный сервер PeerJS.

Если появляется ошибка «Нет связи с облачным сервером PeerJS», значит `0.peerjs.com` недоступен с этого компьютера. Возможные причины:
- VPN включён только на одном из ПК;
- мешает антивирус или блокировка у провайдера;
- в браузере стоит блокировщик.

Проще всего в этом случае использовать способ 1.

Проверка на одном компьютере: добавьте к адресу `?local=1` и откройте игру в двух вкладках.

## Сохранения

Игра сохраняется сама на каждом рассвете, при выходе в меню и кнопкой "Сохранить" в паузе.
"Один игрок" -> "Продолжить" загружает последнее сохранение. Вдвоём: если вы уже играли с этим напарником, хост увидит "Продолжить / Новая игра".
Где хранится: при запуске через `server.py` - в папке `saves/` рядом с игрой; на GitHub Pages - в браузере (на другом компьютере или в другом браузере его не будет).
Монстры не сохраняются - после загрузки лес заселяется заново. Удалить старые сохранения - кнопка "Сохранения" в главном меню.

## Сложность

Перед игрой, на экране выбора профессии, выбирается сложность (запоминается; в игре вдвоём её выбирает создатель комнаты, у второго игрока она та же). Текущая сложность видна в меню паузы.

- **Аркада** (по умолчанию): 150 здоровья, урон по монстрам ×1,5, монстры бьют на 30% слабее, здоровье восстанавливается в 2,5 раза быстрее, костёр лечит в 2,5 раза сильнее и дальше, голод слабее, возрождение за 8 с, на старте 30 $, смена вариантов умений дешевле (20 / 35 / 50 $), боссы зовут подмогу реже.
- **Хардкор**: все значения как в `config.js`.

Все настройки аркады лежат в отдельном файле **`arcade.js`**: там перечислено только то, чем аркада отличается от хардкора (те же имена параметров, что в `config.js`). Хотите поменять аркаду — правьте `arcade.js`; хардкор при этом не меняется. Новые общие множители в `config.js`: `PLAYER_DAMAGE_MULT` (урон по монстрам) и `MONSTER_DAMAGE_MULT` (урон монстров по героям).

## Управление

| Действие | Клавиши |
|---|---|
| Движение | Левая кнопка мыши (клик или удержание) / стрелки / WASD |
| Бег (+20% скорости, сытость тратится в 4 раза быстрее) | Пробел (удерживать) |
| Всегда бегом (тогда пробел — идти шагом) | Caps Lock или галочка в меню паузы |
| Направление взгляда | Мышь |
| Выбрать боевой навык (когда заполнилась шкала опыта) | 1 / 2 / 3 или клик; K — открыть позже |
| Съесть | E или клик колесом мыши |
| Постройка профессии | T / Y |
| Улучшить главный костёр | U (стоя рядом) |
| Выбрать умение при повышении уровня | 1 / 2 / 3 или клик по карточке |
| Показать сборку (умения и характеристики) | Tab |
| Пауза | Esc |

Когда сытость падает до 10% и в рюкзаке есть еда, герой **ест сам** (`AUTO_EAT_AT`). Шаг стал на 20% медленнее (`PLAYER_SPEED`), бег быстрее шага на 20% (`RUN_SPEED_MULT`), но на бегу голод растёт вчетверо (`RUN_FOOD_MULT`). На телефоне бег включается кнопкой с бегущим человечком над кнопкой «Съесть».

Начальное оружие, боевые навыки, рубка деревьев и работа киркой срабатывают **автоматически**, когда цель рядом. Так же сами собираются ягоды и открываются сундуки. **Опыт, монеты и еда** за победы и находки сразу попадают к игроку - на землю падают только дерево, шкуры, уголь и руда.

## Игра с телефона

Откройте ту же ссылку в браузере телефона — сенсорное управление включится само (принудительно: `?mobile=1`, выключить: `?mobile=0`). Удобнее держать телефон горизонтально; при старте игра переходит во весь экран (кнопка «Во весь экран» есть и в паузе).

- **Джойстик в любом месте экрана**: коснитесь и ведите палец — он появится там, где вы коснулись. Короткий тап без движения — как тап по земле.
- **Тап** по земле — идти туда, поднять предмет, поставить постройку в режиме стройки.
- **Долгое нажатие** (заполняется кольцо) — как правый клик мыши: меню здания, бревна в костёр, шкуры на склад, еду на кухню.
- Всё лишнее спрятано: на экране только состояние (день, здоровье, сытость), казна, панель навыков и кнопка «Съесть». Иконки справа сверху открывают панели: ⏸ пауза, 🔨 стройка, 🎒 рюкзак (тап по ячейке — выбросить, по еде — съесть), 🧭 карта, ✓ цели. Повторный тап или тап мимо закрывает панель.
- Тап по ячейке навыка внизу показывает его описание. Сборка персонажа — в меню паузы («Моя сборка»).
- Масштаб картинки на телефоне задаёт `VIEW_HEIGHT_MOBILE` в `config.js`.

## Правила

- **Цель:** пережить 99 ночей.
- **Туман:** днём скрывает 1/3 экрана, ночью 2/3. Костры и факелы разгоняют туман и тьму.
- **Лес закрывает обзор:** взгляд проходит сквозь листву не глубже одного-двух деревьев, дальше туман (`VISION_BLOCK`).
- **Еда:** сытость постоянно падает. Мясо выпадает из монстров (редко, `MEAT_DROP_MULT` = 0.2), ягоды растут на кустах, печёную морковь и тыкву продают торговцы поселений. Огорода (грядок и семян) в игре больше нет. Когда сытость ниже 10%, индикатор голода мигает.
- **Семена редкие:** они лежат в сундуках и изредка выпадают из монстров (чаще из сильных).
- **Оружие:** у каждой профессии своё **начальное оружие** — это боевой навык, уже полученный в начале игры: охотник — охотничий лук, инженер — гаечный ключ, программист — лазерная указка, архитектор — молоток. По силе оно как обычный навык (волк на 1-й ночи — 6–7 ударов) и улучшается опытом, как остальные навыки, и не занимает один из 3 слотов. **Топор — только инструмент**: рубит деревья, монстров не бьёт.
- **Автоподбор** предметов по умолчанию включён (выключается в меню паузы (Esc) или клавишей **F**). Монеты и опыт подбираются всегда.
- **Костёр** в лагере один — главный, новые костры строить нельзя. Правый клик по костру с бревнами в рюкзаке — сразу отдать все бревна в огонь (если далеко, персонаж сам подойдёт).
- **Виды локаций:** руины, лагерь разбойников (разбойники и арбалетчики, вдвое больше монет), упавшая тарелка (пришельцы с лучемётами, железо и много опыта), кладбище зверей (костяные волки и скелеты, шкуры), избушка колдуньи на курьих ножках (колдуньи, пауки, плевуны; больше опыта), грибная поляна (грибовики со спорами; больше монет), медвежья берлога (медведи; мясо и шкуры). Каждый вид встречается хотя бы 2 раза (`SITE_KINDS`, `SITE_KIND_MIN`).
- **Охрана — случайный пак:** группа монстров или (с шансом `ELITE_CHANCE` = 35%) один **босс лагеря**: крупный, в короне, с именем (Атаман, Капитан пришельцев, Медведь-шатун…). Его здоровье равно здоровью всей группы ×1.2, при смерти он даёт монеты за всех.
- **Рост локаций от костра** (`SITE_GROW`): на каждом уровне главного костра поляна становится шире (4 → 5 → 6,5 → 8 тайлов, деревья на новой земле исчезают), появляются новые постройки, в каждую неразграбленную группу приходит ещё один страж, боссы лагерей крепнут (+30% здоровья) и растут, а сундуки дают на 40% больше монет, опыта, угля и мяса за уровень.
- **Логова:** в лесу 26 охраняемых логов с сундуками: монеты, опыт и **одежда** (см. «Снаряжение»). Чем дальше от лагеря, тем сильнее охрана (×1.6 … ×4.6) и лучше вещи. 6 логов **скрыты**: тропы к ним нет, вокруг сплошное кольцо леса — прорубайтесь топором. Внутри самая сильная охрана (×5.5) и лишняя вещь. Семена теперь дают монстры и торговец, железо — залежи (кирка), боссы и громилы в глубине леса.
- **Чащи:** участки почти сплошного леса, через них можно только прорубиться.
- **Железо** — редкий ресурс: залежи в дальнем лесу (нужна кирка), боссы, изредка громилы в глубине леса. Занимает место в рюкзаке, сдаётся на склад у лесопилки. Нужно для высоких уровней зданий, топора (4–5), боевых навыков (4–5) и легендарных умений у торговца.
- **Камень и железная руда:** в дальних участках леса лежат большие кучи камней и маленькие железные скалы (`ORES`). Их разбивает только **кирка** — 15 ударов, бьёт сама, когда стоите рядом; залежь возвращается через 3 дня. Кирку делают в мастерской инженера 3-го уровня (`PICKAXE_CRAFT`) или покупают у торговца. **Камень** сдаётся на склад и нужен для высоких уровней зданий (`STONE_UPGRADE`).
- **Ночь:** появляются Тени, которые боятся света костра. Все монстры становятся охотниками и идут на игрока. С каждой ночью монстры сильнее и их больше.
- **Костёр** лечит тех, кто стоит рядом. Если подойти к нему с дровами, игрок подкинет их сам.

## Профессии

Профессию выбирают перед началом игры, в игре вдвоём каждый выбирает свою.

| Профессия | Старт | Способность |
|---|---|---|
| **Охотник** | криты, больше мяса | Ставит **метки**: помеченные враги получают больше урона от всех источников, включая турели и дронов |
| **Инженер** | +3 инженерии | **T** — автотурель. **T** рядом с вышкой архитектора — пушка на вышку |
| **Программист** | скорость атаки, удача | **T** — **модуль** на постройку: турели и пушке — наведение, вышке — лазер, частоколу — электрозабор, костру — маяк |
| **Архитектор** | +20 HP, +2 брони | **T** — частокол (монстры не проходят), **Y** — вышка (разгоняет туман). Постройки на 40% дешевле, умеет их чинить |

**Синергии.** У каждой профессии есть по 3 умения-синергии, по одному с каждой другой профессией. Они выпадают, только если в игре есть игрок-партнёр:

| | с Охотником | с Инженером | с Программистом | с Архитектором |
|---|---|---|---|---|
| **Охотник** | — | Приманка: турели сильнее по меткам | Цифровой прицел: дроны и лазеры бьют метки | Гнездо снайпера: урон у вышки |
| **Инженер** | Шрапнель: выстрелы по меткам разрываются | — | Совместимость: турели с модулем стреляют быстрее | Укреплённая позиция: турели у частокола бьют сильнее |
| **Программист** | Тепловизор: метки видны сквозь туман | Сеть наведения: дальность и крит турелей | — | Электрозабор: весь частокол бьёт током |
| **Архитектор** | Бойницы: охотники у построек стреляют дальше | Лафет: пушки на вышках сильнее | Модульная конструкция: модули на постройках сильнее | — |

## Боевые навыки и опыт

- За каждого побеждённого монстра сразу начисляется **опыт** (стражи логов и монстры глубоко в лесу дают больше), а монеты и еда сразу попадают в казну и рюкзак - подбирать не нужно. Заполнилась голубая шкала над панелью навыков — выберите 1 из 3 вариантов. Шкала с каждым уровнем набирается дольше (`XP_NEED`). В игре вдвоём напарник получает половину опыта.
- За игру можно взять **не больше 3 навыков** (плюс начальное оружие). Дальше каждый уровень опыта улучшает взятые навыки, до 7-го уровня: +80% общей силы за уровень (перезарядка −8%, на 3-м и 5-м уровнях +1 снаряд, дрон или цель, остальное — урон удара). У любого навыка 5-й уровень = ×4.2 урона в секунду, 7-й — ×5.8. Уровни 4 и 5 требуют 1 и 2 железа, 6-й — 3, 7-й — 4.
- **Баланс:** всё оружие вначале слабое. Урон в секунду по одной цели на 1-м уровне: начальное оружие 5–6, обычный навык 5–7, навык по площади 3–4 на каждую цель. Сильным персонаж становится только за счёт удачных улучшений: уровни навыков, «Сила», крит, скорость атаки, мастерская. «Меткость» и «Мощь клинка»: +1 ≈ +1 урона в секунду каждому навыку своего типа (для веера из 6 дробин и для редкого мощного выстрела одинаково).
- В карточке навыка показан примерный **урон в секунду** по одной цели — по нему удобно сравнивать варианты.
- Если монстр или игрок стоит **за деревом, зданием или скалой**, препятствие становится полупрозрачным, а спрятавшийся монстр подсвечивается красным контуром.
- Выбор можно отложить («Выбрать позже») и открыть клавишей **K** или кликом по мигающей плашке.
- Умения за ночь (Сила, Скорость атаки, Мультивыстрел, Меткость, Мощь клинка и другие) усиливают и навыки.

|---|---|
| Охотник | Лук, Арбалет, Метательные ножи, Копьё, Капканы, Ловчая сеть, Огненные стрелы, Дождь стрел, Бумеранг, Ловчий сокол, Меткий выстрел, Отравленные дротики |

## Развитие

- Каждый рассвет даёт +1 уровень и выбор 1 из 3 умений (как в Brotato). Каждые 10 уровней вместо обычного умения даётся **супер-умение**: метеориты, буря клинков, громовержец, бессмертие и другие.
- Всего около 50 обычных умений и 14 супер-умений. У многих есть плата (например, «Стеклянная пушка»: +урон, −броня).
- **Уровень главного костра** (1–4, растёт от бревен и угля в огне) определяет редкость предлагаемых умений: обычные → улучшенные → редкие → легендарные. Удача повышает шанс получить более редкое.
- **Сменить варианты** умения или боевого навыка можно за монеты из казны лагеря: 1-я смена в этом выборе — 30 $, 2-я — 50 $, 3-я и дальше — по 70 $ (`REROLL_COINS`). В следующем выборе цена снова с 30 $.
- Монстры усиливаются каждую ночь: к 99-й ночи их здоровье вырастает примерно в 35 раз, урон примерно в 14 раз. Без удачной сборки не выжить.
- Днём в лесу волки (и они крепнут с каждой ночью), ночью вместо волков приходит нежить: скелеты с 1-й ночи, зомби с 5-й, скелеты-лучники с 9-й, личи с 15-й. С нежити не падает еда — только монеты и опыт, запасайтесь днём. Упыри, пауки и вожаки ходят и днём, и ночью; тени, плевуны и громилы — только ночью.
- **Боссы** приходят каждые 5–7 ночей: Лесной великан, Повелитель стаи, Болотная ведьма, Каменный голем. Перед каждым ударом босс замахивается, и на земле появляется **красная зона** поражения. Урон получает только тот, кто не успел из неё выйти. За победу над боссом каждый игрок получает бонусное умение.
- **Подмога боссов** (`BOSS_SUMMON`): в бою ночной босс и босс лагеря (с короной) примерно раз в 15 секунд зовут подмогу — по 2 монстра, не больше 4 одновременно (у босса лагеря — 3, из стражи его локации). Под призванными лиловый круг. С подмоги **ничего не выпадает** (ни опыта, ни монет, ни мяса), сундук она не охраняет, живёт 45 секунд и исчезает вместе со своим боссом.

## Еда, кухня, рюкзак

- Всё можно есть сырым, но сырое мясо, морковь и тыква отнимают здоровье. Ягоды лечат +1.
- **Полевая кухня** стоит у главного костра. Подойдите к ней (или правый клик / долгое нажатие по кухне, или кнопка «Отдать всю еду» в её меню) — вся сырая еда встанет в очередь: морковь 5 с, мясо 10 с, тыква 20 с. Готовые блюда ставятся на стол справа от кухни (над ним — «готово ×N»); подойдите, и они сами попадут в инвентарь. Жареное мясо лечит +5. Кухня работает, только пока горит главный костёр.
- **Рюкзак** вмещает 7 материалов: бревна, шкуры, уголь, железо, камень (доски лежат на складе и места не занимают). Еда и монеты места не занимают. Окно рюкзака находится внизу слева:
  - клик по ячейке выбрасывает предмет;
  - клик по еде в верхней панели съедает её.
- **Предметы поднимаются кликом мыши.** Если предмет далеко, персонаж подойдёт сам. Одним кликом поднимаются и такие же предметы рядом. Автоподбор включается параметром `AUTO_PICKUP`.
- **Лесопилка:** подойдите к ней, и бревна из рюкзака встанут в очередь (до 30). Каждое бревно пилится в доску **32 секунды**, доска сразу уходит на **склад**. Уровень лесопилки добавляет параллельные пилы: на 2-м уровне пилятся сразу 2 бревна, на 3-м — 3 и т. д. (над лесопилкой — полоска на каждое бревно, в подписи «пилит 2/2»). Кухня так же: уровень N — N блюд одновременно.
- **Склад** существует только как числа в верхней панели: общий для всех игроков и бесконечный. Стройка и улучшения выполняются, только если на складе хватает досок, сразу целиком.

## Лес и топор

- Дерево рубится топором: 1-й уровень — 10 ударов, 2-й — 8, 3-й — 6, 4-й — 4, 5-й — 2 (`AXE_HITS`). Монстров топор не бьёт. Улучшить топор можно **в меню лесопилки** (правый клик по ней, на телефоне — долгое нажатие; любой профессией), в мастерской инженера или у торговца. Цена: монеты и доски, 4-й и 5-й уровни — ещё и железо.
- Лес восстанавливается сам:
  - срубленное дерево оставляет **пень**, через 150 с на нём появляется **молодой побег**;
  - на пустых местах леса побеги появляются сами, чаще там, где лес гуще; внутри территории лагеря их не бывает;
  - побег нельзя срубить, он не мешает ходить и через **2 игровых дня** вырастает в дерево.
- Настройки в `config.js`: `TREE_HP`, `AXE_HITS`, `AXE_UPGRADE`, `STUMP_TO_SAPLING`, `SAPLING_GROW_DAYS`, `SAPLING_SPAWN_INTERVAL`, `SAPLING_MAX`.

## Погода

Погода меняется сама каждые 80–150 секунд (`WEATHER`); первые 150 секунд всегда ясно. Текущая погода — в плашке справа от блока здоровья (на телефоне — значок рядом с днём).

| Погода | Что меняет |
|---|---|
| Ясно | ничего |
| Дождь | костёр прогорает ×1,6, обзор чуть меньше |
| Гроза | как дождь, но сильнее; рядом бьют молнии: светлый круг на земле — через 1,4 с удар (игроку −14% здоровья, монстрам −45%) |
| Туман | обзор ×0,6, но и монстры замечают вас с 60% расстояния |
| Снегопад | все ходят на 12% медленнее, голод ×1,35 |
| Зной (только днём) | голод ×1,5, монстры вялые (−12% скорости), костёр прогорает медленнее |

## Главный костёр

- У костра есть **шкала топлива**, она постоянно прогорает: 1 деление за 20 секунд. Потухший костёр разгорается от бревна, но его свет сначала всего 1/5 и растёт вместе с топливом. Подойдите к костру, и бревна и уголь из рюкзака сами уходят в огонь, по одной штуке раз в 3 секунды (`FIRE_FEED_INTERVAL`). Бревно даёт 1 деление, уголь 30.
- Когда шкала заполнена до конца, костёр получает новый уровень, и шкала **расширяется**. Пример: на 1-м уровне 20 делений; заполнили их — на 2-м уровне шкала 20 + 90 = 110, из них 20 заполнены, 90 пусты. Дальше +135, +180 и +225 — всего 5 уровней (со 2-го уровня прокачка втрое дольше). Полный свет костёр даёт уже при 30 делениях (`FIRE_LIGHT_FULL`).
- Уровень костра определяет **туман войны** (сколько мира открыто), территорию лагеря, редкость умений, свет и лечение. Достигнутый уровень не теряется, даже если огонь прогорел.
- **Уголь** лежит в логовах монстров (сундуках охраняемых руин) и выпадает из боссов.
- С модификацией лесопилки «Углежог» уголь со склада сам уходит в костёр, когда тот прогорает.
- Настройки в `config.js`: `FIRE_LEVEL_STEPS`, `FUEL_VALUES`, `FIRE_BURN_RATE`.

## Здания: меню, улучшения, модификации

**Правый клик по зданию** открывает его меню, с любого расстояния. В меню:
- что здание делает и его текущие показатели;
- **улучшения:** уровень, что даст следующий, цена в досках (для высоких уровней — и в железе, `IRON_UPGRADE`), кто может улучшать;
- **модификации:** 3 варианта на выбор, действует одна. Установка стоит 15 досок и 10 монет, смена — снова за плату.

Закрыть меню: ✕, Esc или правый клик по пустому месту. Клавиша **U** быстро улучшает здание, рядом с которым вы стоите.

Все здания — препятствия: сквозь них не проходят ни игроки, ни монстры. Монстры, упёршись в постройку, ломают её.

## Экономика

Монеты — общая **казна** команды.

**Доходы:**
- монеты из монстров (в глубине леса вдвое больше) и из сундуков — подбираются сами, когда проходишь рядом;
- лавка охотника;
- майнинг и торговля на бирже программиста;
- налог ратуши архитектора.

**Расходы:**
- ежедневное содержание построек;
- торговец;
- мастерская инженера.

Если на рассвете монет не хватило на содержание, турели, пушки и лазеры отключаются, а кухня и лесопилка работают вполовину. Как только в казне появятся деньги, долг гасится сам.

Экономические здания профессий строятся клавишей **H**, по одному на игрока:

| Профессия | Здание | Что делает |
|---|---|---|
| Охотник | Лавка | продаёт шкуры, готовую еду и доски, рядом появляются монеты |
| Программист | Крипто-биржа | майнит монеты; можно купить и продать токен AviCoin, курс скачет, бывают обвалы и взлёты |
| Инженер | Мастерская | улучшает топор, на 3-м уровне делает кирку; её уровень усиливает боевые навыки всех игроков |
| Архитектор | Ратуша | снижает содержание всех построек на 30% и собирает налог каждый рассвет |

Торговец (каждый 3-й день) продаёт всем расширение рюкзака, кирку и умения (охотнику умения на 25% дешевле).

## Лагерь и лес

- Костёр лечит игроков и жжёт монстров рядом. Нежить (упыри, тени, плевуны) он жжёт в 2,5 раза сильнее.
- **Территория лагеря** отмечена кольцом кольев и растёт с уровнем костра: 320 → 450 → 600 → 780 → 900. Внутри неё монстры не появляются.
- **Туман войны.** Открыта только земля вокруг лагеря; за её краем — плотная клубящаяся пелена, зайти туда нельзя. С каждым уровнем костра туман отступает: 1250 → 1800 → 2450 → 3300 пикселей от костра, а на **5-м уровне** рассеивается совсем — открыт весь мир и поселения сторон света (`FOW_RADIUS`). Граница видна на миникарте голубым кругом.
- **Уровни монстров.** Над каждым монстром — табличка с уровнем. Уровень = номер ночи + 5 за каждое кольцо тумана войны от лагеря (`ZONE_LEVEL`): у лагеря на 1-й ночи монстры 1-го уровня, во втором кольце — 6-го, в третьем — 11-го и т. д. Здоровье и урон — как у монстров ночи с этим номером. Цвет таблички: серый — обычный для этой ночи, жёлтый, оранжевый, красный — всё опаснее. Стража сундуков растёт с ночами вдвое медленнее (`GUARD_NIGHT_LEVEL`).
- **Сундук заперт, пока жива его стража** — на нём висит замок, а в подписи локации написано, сколько стражей осталось.
- **Суперудары монстров.** Перед суперударом монстр замирает, и на земле появляется красная подсказка. Если убить монстра во время замаха, удар отменяется.
  - Волк и вожак: прыжок по прямой.
  - Упырь: размах когтями конусом.
  - Тень: взрыв вокруг себя.
  - Паук: паутина под игроком, замедляет.
  - Плевун: ядовитый залп по нескольким точкам.
  - Громила: удар дубиной.
- Монстры ходят плавно: разгоняются, поворачивают, виляют и обходят деревья. Скорость монстров задаёт параметр `MONSTER_SPEED_MULT`. Ночных монстров втрое меньше, чем раньше.

## Земли сторон света и поселения

Карта выросла: прежний лес стал **лесным ядром** в центре (`CORE_TILES` = 160), а вокруг него в каждой стороне света лежит свой биом (`WORLD_SIZE_TILES` = 300, `BIOMES`). Лес плавно переходит в биом.

| Сторона | Биом | Что там | Поселение | Торговцы |
|---|---|---|---|---|
| Север | Снежная тайга | заснеженные ели, лёд на озёрах, всегда идёт снег | Северная деревня (избы, колодец, снеговик) | Меховщик (шапки, куртки, перчатки) · Рыбак (жареное мясо, морковь, уголь) |
| Восток | Степь | золотая трава, акации, мало деревьев, лёгкий зной | Стойбище (вигвамы, тотем, сушилка шкур) | Шаман (ягоды, жареное мясо, шарики опыта) · Кожевник (обувь, штаны, перчатки) |
| Юг | Топи | много воды, ивы с плетями, камыш, туман | Деревня на деревьях (дома на деревьях, хижина на сваях, мостки) | Травница (печёная тыква и морковь, ягоды, опыт) · Следопыт (шапки, обувь, штаны) |
| Запад | Каменные холмы | камни, много залежей железа и камня | Каменный город (дома, башня, фонтан, стена) | Кузнец (шлемы, куртки, штаны, железо) · Лавочник (рюкзак +2, доски, уголь, камень, кирка) |

- К каждому поселению от лагеря ведёт **дорога**, на миникарте они отмечены домиками.
- В поселении горит **вечный костёр**: лечит, жжёт монстров, не гаснет и не требует дров. Рядом (`TOWN_SAFE`) монстры не появляются.
- Подойдите к торговцу — откроется его прилавок. Платите из общей казны. Одежда (3 вещи у каждого торговца одежды) попадает в снаряжение; товары вроде досок, железа, камня и угля — на склад лагеря. Прилавки обновляются каждый рассвет, «рюкзак» и «кирка» — одна покупка за день (`TOWNS`, `TOWN_GOODS`, `TOWN_GEAR`).
- Земли сторон света открываются на 5-м уровне костра. Монстры там — 4-го и 5-го колец тумана войны: на 15–20 уровней сильнее, чем у лагеря.

## Снаряжение

Главная награда сундуков — одежда (`GEAR`, `CHEST_GEAR`): 1 вещь, у босса лагеря и в скрытом логове — 2.

- **5 ячеек:** голова (кепка, капюшон, шлем, шляпа, бандана), куртка (рубаха, куртка, кольчуга, мантия, жилет), перчатки (перчатки, рукавицы, наручи), штаны (штаны, поножи, шаровары), обувь (ботинки, сапоги, мокасины). Надетое видно на герое.
- **Редкость:** обычная (только базовый бонус), магическая (+1 случайное свойство), редкая (+2), легендарная (+3, герой светится). Чем дальше локация, тем чаще редкие вещи; у боссов лагерей и в скрытых логовах — ещё лучше.
- **Сила вещи** растёт с дальностью локации, уровнем костра и если локацию охранял босс. Свойства: здоровье, броня, уклонение, скорость, урон, скорость атаки, крит, регенерация, удача, вампиризм, радиус подбора, шипы.
- **Окно снаряжения:** клавиша **I** (на телефоне — иконка с футболкой или «Снаряжение» в паузе). Слева — герой и 5 ячеек, справа — сундук героя на 10 вещей. Нажмите на вещь — увидите свойства и разницу с надетой (зелёный — лучше, красный — хуже). Значок ▲ — вещь лучше надетой. Двойной клик — надеть. Лишнее **разбирается на монеты**: 4 × (редкость + 1) × сила.
- Пустая ячейка заполняется сама. Если сундук героя полон, новая вещь сразу разбирается на монеты.
- Герой стал на 20% меньше (`PLAYER_SCALE`) и на 15% медленнее (`PLAYER_SPEED` 132): скорость теперь можно вернуть обувью.

## Настройки

Все игровые переменные собраны в **`config.js`**, у каждой есть комментарий. Там задаются:
- мир: размер, длительность дня и ночи, туман;
- персонаж: скорость (`MOVE_SPEED_MULT`), здоровье, топор, боевые навыки (`ABILITIES`), опыт (`XP_*`), железо (`IRON`);
- лес: плотность, чащи (`THICKET`), логова и скрытые логова, зрение сквозь лес (`VISION_BLOCK`);
- монстры: характеристики, рост силы, таблица появления, боссы и их приёмы;
- профессии, постройки, модули;
- все умения и синергии со значениями по редкостям;
- еда, костёр, сеть, звук и графика. После изменения достаточно перезагрузить страницу.

## Структура

```
index.html      — страница и меню
style.css       — оформление меню
arcade.js       — отличия режима «Аркада» от хардкора (config.js)
config.js       — ВСЕ настройки игры с описаниями
js/utils.js     — случайные числа, шум, математика
js/world.js     — генерация мира (лес, озёра, тропы, руины, лагерь) и столкновения
js/skills.js    — умения, характеристики, выбор при повышении уровня
js/sim.js       — игровая логика: игроки, бой, постройки, монстры, боссы, еда, день/ночь, сеть
js/sprites.js   — процедурная отрисовка спрайтов (деревья, камни, сундуки, иконки)
js/buildings.js — здания в стиле концепта (доски, сланцевые крыши, окна), кэшируются в 2×
js/fx.js        — частицы, всплывающие надписи и синтезированные звуки
js/render.js    — отрисовка мира, персонажей, тумана, освещения, интерфейса и миникарты
js/net.js       — сеть (локальный сервер / PeerJS / канал для тестов)
js/save.js      - сохранения (браузер или папка saves/ у server.py)
server.py       — локальный сервер для игры вдвоём без интернета (Python 3)
js/main.js      — меню, управление, игровой цикл
```

Вся графика рисуется кодом, внешних картинок нет. Сборка не нужна: это обычные файлы, их можно открыть через любой статический хостинг.
