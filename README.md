# Avi-Bro: 99 ночей в лесу

Браузерная 2D-игра на выживание для одного или двух игроков. Работает в любом современном браузере на ПК без установки.

## Как опубликовать на GitHub Pages (один раз)

1. Загрузите содержимое этой папки в репозиторий `https://github.com/Assinross/Avi-Bro` (в корень, рядом с `index.html`):
   ```bash
   cd ~/avi-game/avi-bro
   git init
   git remote add origin https://github.com/Assinross/Avi-Bro.git
   git add .
   git commit -m "Avi-Bro: первая версия игры"
   git branch -M main
   git push -u origin main
   ```
2. На GitHub откройте **Settings → Pages**. В разделе **Build and deployment** выберите *Source: Deploy from a branch*, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
3. Через 1–2 минуты игра будет доступна по адресу:
   **https://assinross.github.io/Avi-Bro/**

## Как обновить игру

После любых изменений в папке:
```bash
cd ~/avi-game/avi-bro
git add .
git commit -m "что изменилось, например: усилил монстров"
git push
```
Сайт обновится через 1–2 минуты. Если браузер показывает старую версию, обновите страницу через `Ctrl+Shift+R`.

## Игра вдвоём

1. Оба игрока открывают ссылку на игру (компьютеры в одной сети Wi-Fi).
2. Первый игрок: **Игра вдвоём → Создать комнату**. Появятся 4-значный код и ссылка-приглашение.
3. Второй игрок вводит код и нажимает **Войти**. Можно также просто открыть ссылку-приглашение.

Соединение устроено через WebRTC (библиотека PeerJS). Бесплатный сервер PeerJS нужен только для «рукопожатия», дальше данные игры идут напрямую между компьютерами по локальной сети. Первый игрок (хост) считает всю логику мира, второй получает состояние 15 раз в секунду. Если второй игрок отключился, он может вернуться по тому же коду.

**Без интернета.** Если в сети нет доступа в интернет, запустите на любом ПК свой сервер соединения: `npx peerjs --port 9000`. Затем укажите его адрес в `config.js`:
```js
PEER_SERVER: { host: '192.168.1.10', port: 9000, path: '/', secure: false },
```

**Проверка на одном компьютере.** Добавьте к адресу `?local=1` и откройте игру в двух вкладках. Вкладки общаются напрямую, без сети.

## Управление

| Действие | Клавиши |
|---|---|
| Движение | Левая кнопка мыши (клик или удержание) / стрелки / WASD |
| Направление взгляда | Мышь |
| Выбор оружия | 1–5, колесо мыши, клик по слоту |
| Съесть | E |
| Посадить семя в ближайшую грядку | R |
| Построить грядку у курсора | G (8 дерева) |
| Построить костёр у курсора | B (12 дерева) |
| Постройка профессии | T / Y |
| Улучшить главный костёр | U (стоя рядом) |
| Выбрать умение при повышении уровня | 1 / 2 / 3 или клик по карточке |
| Показать сборку (умения и характеристики) | Tab |
| Пауза | Esc |

Атака, стрельба и рубка деревьев срабатывают **автоматически**, когда цель в радиусе оружия или топора. Так же автоматически собираются ягоды, урожай и предметы и открываются сундуки.

## Правила

- **Цель:** пережить 99 ночей.
- **Туман:** днём скрывает 1/3 экрана, ночью 2/3. Костры и факелы разгоняют туман и тьму.
- **Еда:** сытость постоянно падает. Мясо выпадает из монстров, ягоды растут на кустах, морковь и тыкву можно вырастить в огороде.
- **Семена редкие:** они лежат в сундуках и изредка выпадают из монстров (чаще из сильных).
- **Оружие:** нож, копьё, лук, арбалет, винтовка. Всё, кроме ножа, лежит в сундуках среди руин под охраной. Чем дальше руины от лагеря, тем сильнее охрана и лучше награда. Стражи замечают игрока издалека и бегут за ним.
- **Ночь:** появляются Тени, которые боятся света костра. Все монстры становятся охотниками и идут на игрока. С каждой ночью монстры сильнее и их больше.
- **Костёр** лечит тех, кто стоит рядом. Если подойти к нему с дровами, игрок подкинет их сам.

## Профессии

Профессию выбирают перед началом игры, в игре вдвоём каждый выбирает свою.

| Профессия | Старт | Способность |
|---|---|---|
| **Охотник** | лук, криты, больше мяса | Ставит **метки**: помеченные враги получают больше урона от всех источников, включая турели и дронов |
| **Инженер** | +3 инженерии | **T** — автотурель. **T** рядом с вышкой архитектора — пушка на вышку |
| **Программист** | боевой дрон, скорость атаки, удача | **T** — **модуль** на постройку: турели и пушке — наведение, вышке — лазер, частоколу — электрозабор, костру — маяк, грядке — автополив |
| **Архитектор** | +20 HP, +2 брони | **T** — частокол (монстры не проходят), **Y** — вышка (разгоняет туман). Постройки на 40% дешевле, умеет их чинить |

**Синергии.** У каждой профессии есть по 3 умения-синергии, по одному с каждой другой профессией. Они выпадают, только если в игре есть игрок-партнёр:

| | с Охотником | с Инженером | с Программистом | с Архитектором |
|---|---|---|---|---|
| **Охотник** | — | Приманка: турели сильнее по меткам | Цифровой прицел: дроны и лазеры бьют метки | Гнездо снайпера: урон у вышки |
| **Инженер** | Шрапнель: выстрелы по меткам разрываются | — | Совместимость: турели с модулем стреляют быстрее | Укреплённая позиция: турели у частокола бьют сильнее |
| **Программист** | Тепловизор: метки видны сквозь туман | Сеть наведения: дальность и крит турелей | — | Электрозабор: весь частокол бьёт током |
| **Архитектор** | Бойницы: охотники у построек стреляют дальше | Лафет: пушки на вышках сильнее | Модульная конструкция: модули на постройках сильнее | — |

## Развитие

- Каждый рассвет даёт +1 уровень и выбор 1 из 3 умений (как в Brotato). Каждые 10 уровней вместо обычного умения даётся **супер-умение**: метеориты, буря клинков, громовержец, бессмертие и другие.
- Всего около 50 обычных умений и 14 супер-умений. У многих есть плата (например, «Стеклянная пушка»: +урон, −броня).
- **Уровень главного костра** (1–4, клавиша **U**) определяет редкость предлагаемых умений: обычные → улучшенные → редкие → легендарные. Удача повышает шанс получить более редкое.
- Неудачные варианты можно перебросить за дерево.
- Монстры усиливаются каждую ночь: к 99-й ночи их здоровье вырастает примерно в 35 раз, урон примерно в 14 раз. Без удачной сборки не выжить.
- Первые 3 ночи в лесу только волки, и они крепнут с каждой ночью. Потом постепенно добавляются упыри, тени, пауки, вожаки, плевуны и громилы.
- **Боссы** приходят каждые 5–7 ночей: Лесной великан, Повелитель стаи, Болотная ведьма, Каменный голем. Перед каждым ударом босс замахивается, и на земле появляется **красная зона** поражения. Урон получает только тот, кто не успел из неё выйти. За победу над боссом каждый игрок получает бонусное умение.

## Еда, кухня, рюкзак

- Всё можно есть сырым, но сырое мясо, морковь и тыква отнимают здоровье. Ягоды лечат +1.
- **Полевая кухня** стоит у главного костра. Подойдите к ней, и вся сырая еда из рюкзака начнёт готовиться: морковь 5 с, мясо 10 с, тыква 20 с. Готовые блюда появляются рядом с кухней. Жареное мясо лечит +5. Кухня работает, только пока горит главный костёр.
- **Рюкзак** вмещает 7 материалов: бревна, доски, шкуры. Еда, семена и монеты места не занимают. Окно рюкзака находится внизу слева:
  - клик по ячейке выбрасывает предмет;
  - клик по еде в верхней панели съедает её.
- **Предметы поднимаются кликом мыши.** Если предмет далеко, персонаж подойдёт сам. Одним кликом поднимаются и такие же предметы рядом. Автоподбор включается параметром `AUTO_PICKUP`.
- **Лесопилка** (бывший склад): подойдите к ней, и бревна из рюкзака выгрузятся. Она пилит их в доски; на 1-м уровне помещается 10 досок, +5 за каждый следующий уровень. Если в главном костре мало топлива, лесопилка подкидывает туда бревна.
- **Доски** идут на все постройки и улучшения. Берутся сначала из рюкзака, потом с лесопилки.

## Улучшения (клавиша U рядом с объектом)

Доски можно вносить по частям, прогресс сохраняется.

| Что | Эффект | Цена |
|---|---|---|
| Кухня | уровень = сколько блюд готовится одновременно (1…10) | 20, 30, 40… досок |
| Лесопилка | +5 досок вместимости, пилит быстрее | 20, 30, 40… досок |
| Костёр | территория, свет, редкость умений | 40 / 90 / 160 досок |
| Вышка (архитектор) | +30% прочности, +12% дальности | 15 / 25 / 40 / 60 |
| Пушка или турель (инженер) | +60% урона | 15 / 25 / 40 / 60 |
| Модуль (программист) | +60% силы модуля | 20 / 40 |

Урон турелей, пушек и лазеров растёт на 6% каждую ночь.

## Экономика

Монеты — общая **казна** команды.

**Доходы:**
- монеты из монстров (в глубине леса вдвое больше);
- лавка охотника;
- майнинг и торговля на бирже программиста;
- налог ратуши архитектора.

**Расходы:**
- ежедневное содержание построек;
- торговец;
- мастерская инженера.

Если на рассвете монет не хватило на содержание, турели, пушки и лазеры отключаются, а кухня и лесопилка работают вполовину. Как только в казне появятся деньги, долг гасится сам.

Экономические здания профессий строятся клавишей **H**, по одному на игрока:

| Профессия | Здание | Что делает |
|---|---|---|
| Охотник | Лавка | продаёт шкуры, готовую еду и доски, рядом появляются монеты |
| Программист | Крипто-биржа | майнит монеты; можно купить и продать токен AviCoin, курс скачет, бывают обвалы и взлёты |
| Инженер | Мастерская | улучшает оружие в руках: +15% урона за уровень, до 5 уровней, за монеты и доски |
| Архитектор | Ратуша | снижает содержание всех построек на 30% и собирает налог каждый рассвет |

Торговец (каждый 3-й день) продаёт всем семена и расширение рюкзака, а охотнику ещё и умения.

## Лагерь и лес

- Костёр лечит игроков и жжёт монстров рядом. Нежить (упыри, тени, плевуны) он жжёт в 2,5 раза сильнее.
- **Территория лагеря** отмечена кольцом кольев и растёт с уровнем костра: 320 → 450 → 600 → 780. Внутри неё монстры не появляются.
- **Чем глубже в лес, тем опаснее.** У края карты монстры получают до +150% здоровья и +80% урона, а сильные виды встречаются раньше.
- **Суперудары монстров.** Перед суперударом монстр замирает, и на земле появляется красная подсказка. Если убить монстра во время замаха, удар отменяется.
  - Волк и вожак: прыжок по прямой.
  - Упырь: размах когтями конусом.
  - Тень: взрыв вокруг себя.
  - Паук: паутина под игроком, замедляет.
  - Плевун: ядовитый залп по нескольким точкам.
  - Громила: удар дубиной.
- Монстры ходят плавно: разгоняются, поворачивают, виляют и обходят деревья. Скорость монстров задаёт параметр `MONSTER_SPEED_MULT`. Ночных монстров втрое меньше, чем раньше.

## Настройки

Все игровые переменные собраны в **`config.js`**, у каждой есть комментарий. Там задаются:
- мир: размер, длительность дня и ночи, туман;
- персонаж: скорость (`MOVE_SPEED_MULT`), здоровье, урон оружия;
- монстры: характеристики, рост силы, таблица появления, боссы и их приёмы;
- профессии, постройки, модули;
- все умения и синергии со значениями по редкостям;
- еда, огород, костёр, сеть, звук и графика. После изменения достаточно перезагрузить страницу.

## Структура

```
index.html      — страница и меню
style.css       — оформление меню
config.js       — ВСЕ настройки игры с описаниями
js/utils.js     — случайные числа, шум, математика
js/world.js     — генерация мира (лес, озёра, тропы, руины, лагерь) и столкновения
js/skills.js    — умения, характеристики, выбор при повышении уровня
js/sim.js       — игровая логика: игроки, бой, постройки, монстры, боссы, еда, огород, день/ночь, сеть
js/sprites.js   — процедурная отрисовка спрайтов (деревья, камни, сундуки, иконки)
js/fx.js        — частицы, всплывающие надписи и синтезированные звуки
js/render.js    — отрисовка мира, персонажей, тумана, освещения, интерфейса и миникарты
js/net.js       — сеть (PeerJS / локальный канал для тестов)
js/main.js      — меню, управление, игровой цикл
```

Вся графика рисуется кодом, внешних картинок нет. Сборка не нужна: это обычные файлы, их можно открыть через любой статический хостинг.
